# 🧠 MonProva

### *A Smart Digital Platform for Mental Health Care*

![MonProva Banner](https://via.placeholder.com/1200x300?text=MonProva+Mental+Health+Platform)

## 📌 Overview

**MonProva** is a secure, user-friendly mental health platform designed to bridge the gap between patients and mental health professionals. It provides tools for self-assessment, progress tracking, and easy access to professional care—all within a confidential and structured ecosystem.

---

## 🎯 Key Features

### 👤 For Patients

* 📝 **Easy Registration & Login** (Email / Google + Verification)
* 🧪 **Self-Assessment Tests**

  * PHQ-9 (Depression)
  * GAD-7 (Anxiety)
  * PSS-10 (Stress)
* 📊 **Progress Tracking Dashboard** (Visual graphs)
* 📚 **Mental Health Resources**

  * Articles
  * Videos
  * Relaxation Games
* 📅 **Doctor Appointment Booking**

  * Online & Offline consultations
  * Secure payments
* 💬 **Private Help Section**

  * Ask questions confidentially

---

* 👨‍⚕️ **Professional Profile Management**

* 💊 **Prescription Upload & Management**
